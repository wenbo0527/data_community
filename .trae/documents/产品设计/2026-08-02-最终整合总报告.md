## 🎯 用户旅程(整合后效果)

### 旅程 A · 看客户授信额度(4 跳 → 1 跳)
```
分析师 → UnifiedWorkbench 顶部搜索"客户授信"
       → 意图识别命中"客户洞察"
       → GlobalSearchResult 点击 "查看客户洞察"
       → 跳转 /discovery/customer360?keyword=客户授信
       → 客户列表预填搜索,点开看到授信
```

### 旅程 B · 申请外数指标(5 跳 → 0 跳)
```
分析师 → 在指标详情页 → ApplyForMetricButton 弹窗
       → 填使用场景 + 周期 + 通知方式
       → 提交,系统自动审批 + 站内信通知
       → 工作台"我的产出"看到进度
```

### 旅程 C · 人群圈选 → 标签固化(高门槛 → 0 门槛)
```
运营 → 在圈选结果页 → "保存为标签"按钮
     → SaveAudienceAsTagDrawer 自动带入圈选规则
     → 选标签组 + 命名 + 配置刷新频率
     → 一键固化,管理端+探索端+客户 360 同步可见
```

### 旅程 D · 数据治理贯通(0 联动 → 全联动)
```
治理者 → /management/metadata/modeling
       → "字段打标" tab → 选表 dim_user
       → ClassificationViewer 展示:
         ✓ 标准合规率:80% 进度条
         ✓ 分级覆盖率:40% 进度条
         ✓ 每个字段一行: STD_005 · L3 · 关键 · 零售 · 身份证号 · 合规
       → 一键自动打标:基于矩阵推荐 → 一键确认
       → 资产→表→字段→标准→分级→要素 五方同步
```

### 旅程 E · 找产出(找不到 → 一处可见)
```
任意角色 → UnifiedWorkbench → "我的产出" 卡片
        → 6 类分页:工作流/看板/人群/标签/报表/模型
        → 状态徽标:运行中/成功/失败/草稿
        → 点击跳对应模块 + 上下文传递
```

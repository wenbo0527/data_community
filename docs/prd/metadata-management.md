# 元数据管理 - 产品需求

## 1. 背景

元数据是数据治理的基石，涵盖数据从采集到消费全生命周期的元信息。
本模块提供**采集任务 + 业务实体**两大主功能，承担元数据治理的核心职责。

## 2. 核心功能

### 2.1 采集任务

**目标**：统一管理所有数据源的元数据采集任务。

子模块：
- **任务列表**：查看所有采集任务，支持筛选（关键字、数据源类型、采集对象类型）
- **创建任务**：配置任务基础信息（任务名、数据源类型、采集对象）、连接配置、数据登记、关联登记、血缘登记、业务登记

支持的数据源：Doris / Hive / Oracle
采集的对象类型：指标 / API / 变量 / 表

### 2.2 业务实体

**目标**：把物理表绑定到业务语义，构建数据治理的基础映射。

子模块：
- **实体绑定**：把物理表绑定到业务实体（如「贷款申请」「客户画像」）
- **血缘构建**：构建表与表之间的上下游关系，支持自动解析和手动添加
- **标准映射**：把物理字段映射到数据标准（如 GB/T 行业标准）

## 3. 关键指标

- 任务成功率 ≥ 95%
- 实体绑定覆盖率 ≥ 80%
- 标准合规率持续提升

## 4. 用户旅程

```
1. 需求方提出数据采集需求
2. 数据工程师在「创建任务」配置元数据采集规则
3. 提交任务 → 后台运行 → 任务状态在「任务列表」展示
4. 数据治理员在「业务实体」把新采集的表绑定到业务实体
5. 通过「血缘构建」建立表间关系
6. 通过「标准映射」校验字段合规性
```

## 5. 与其他模块的关系

- **数据资产上下架**：消费元数据管理的产出，自动同步到 listing 框架
- **数据分级分类**：消费元数据中的标签、字段信息进行分级判定
- **数据标准治理**：双向联动，标准映射结果回写标准库

## 6. 后续规划

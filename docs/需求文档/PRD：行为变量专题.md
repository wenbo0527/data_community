## 1. 背景与目标

### 1.1 背景

变量台账已经实现：
- 全部 / 效果 / 成本 三种视角切换
- 基础属性 / 技术属性 / 类型化属性 详情
- 血缘、生命周期、监控、操作历史 等 Tab

但是**所有变量都用一套通用视图**展示，**没有针对"行为变量"的专项管理能力**。

### 1.2 行为变量的特殊性

行为变量（来源类型=行为类/交易类）与其他变量类型的本质区别：

| 维度 | 外数变量 | 征信变量 | **行为变量** | 画像变量 |
|---|---|---|---|---|
| **数据来源** | 外部三方 | 央行/同业 | **内部日志** | 内部加工 |
| **单价** | 高（1-3元/次） | 中 | **0** | 0 |
| **覆盖度** | 60-95% | 70-90% | **95-100%** | 100% |
| **时效性** | T+1 / T+0 | T+1 | **实时 / T+1** | T+1 |
| **衰减速度** | 慢 | 慢 | **快**（季节性） | 慢 |
| **隐私风险** | 中（外数授权） | 中 | **高**（行为画像） | 中 |
| **数量** | 中（数百个） | 少（数十个） | **多**（数千个） | 中（数百个） |

**核心差异**：行为变量**量大、易衰减、隐私风险高、单价为零但计算成本不可忽视**。

### 1.3 业务痛点

| 角色 | 痛点 | 期望 |
|---|---|---|
| **分析师** | 找高活跃行为变量困难；不知道哪些在衰减 | 一眼看到活跃度、衰减率 |
| **决策者** | 难以判断行为变量是否还能用 | PSI 稳定性、衰减预警 |
| **预算负责人** | 行为变量"零单价"但实际计算成本高 | 计算资源消耗指标 |
| **合规** | 行为变量涉及隐私，难盘点 | 隐私字段清单 + 等级标签 |
| **运维** | 行为变量数据源系统多（Tlog/CDP/行为埋点） | 系统来源标注 |

### 1.4 目标

| 维度 | 目标 |
|---|---|
| **业务目标** | 让行为变量的发现、评估、监控、合规自检效率提升 50% |
| **产品目标** | 在现有变量台账基础上，提供**行为变量专题入口 + 专属指标体系** |
| **范围** | **仅行为变量**，其他类型不纳入本期 |

## 3. 业务边界与原则

### 3.1 业务边界

**包含**：
- 行为变量的专题入口（变量台账内）
- 行为变量专属列表视图
- 行为变量专属详情页增强
- 行为变量专属评估指标

**不包含**：
- 外数 / 征信 / 画像变量的专项页面（本期仅行为）
- 行为变量的评估计算（数据接入本期不做）
- 行为变量的自动替换 / 下线流程

### 3.2 设计原则

1. **基于现有变量台账**：不另起炉灶，复用现有的列表 / 详情 / 血缘架构
2. **差异化而非平铺**：通过"专题入口 + 专属指标"让行为变量"立体化"
3. **业务优先**：指标选型以业务决策为导向（活跃、衰减、合规），而非技术参数
4. **渐进披露**：列表只展示关键指标，详情展开深度数据

## 4. 核心功能设计

### 4.1 行为变量专题入口

**位置**：变量台账顶部 DmtPageHeader 右侧，与"全部 / 效果 / 成本" 视图切换并列

**形式**：新增一个 **ToggleButton**（图标 + 文字）

```
┌─────────────────────────────────────────────┐
│ 变量台账                  [全部变量 | 行为变量] │
└─────────────────────────────────────────────┘
```

**行为**：
- 点击"行为变量" → 自动应用筛选 `variableType ∈ {行为类, 交易类}`
- 列表自动切换为"行为变量列表视图"（详见 §6.2）
- 顶部统计卡片替换为行为变量专属卡片（详见 §6.2）
- 再次点击 → 回到"全部变量"

### 4.2 行为变量专属统计指标

| 指标 | 定义 | 计算方式 | 业务意义 |
|---|---|---|---|
| **活跃度** | 最近 7 天有数据的天数占比 | count(day_with_data in last_7d) / 7 | 是否"活着" |
| **衰减率** | 覆盖度周环比下降 | (cover_t-1 - cover_t) / cover_t-1 | 是否在衰减 |
| **PSI** | 群体稳定性指标 | SUM((actual% - expected%) × ln(actual% / expected%)) | 是否稳定 |
| **数据新鲜度** | 数据延迟 | max(event_time) - now() | 是否实时 |
| **隐私等级** | 涉及字段的隐私敏感度 | L0=无 / L1=行为 / L2=画像 / L3=身份 | 合规风险 |
| **计算资源** | 单次计算 CPU·秒 | 资源监控埋点 | 计算成本 |

### 4.3 行为变量列表视图

**位置**：`/variable-management/behavior`（专题路由，复用主台账组件）

**与现有列表的区别**：

| 维度 | 现有列表（变量台账） | 行为变量专题列表 |
|---|---|---|
| **数据范围** | 全部类型 | 仅行为类 + 交易类 |
| **列定义** | 见 §6.3 现有 | 增加：活跃度 / 衰减率 / PSI / 隐私等级 |
| **默认排序** | 更新时间倒序 | 活跃度降序 |
| **统计卡片** | 4 个通用卡片 | 4 个行为变量专属卡片 |
| **筛选器** | 类型 / 状态 / 数据源 | 增加：活跃度 / 衰减率 / 隐私等级 |
| **视图切换** | 全部 / 效果 / 成本 | **固定**（效果视角为基础） |

### 4.4 行为变量详情页增强

**位置**：`/variable-management/detail/:id`（现有路由，行为变量分支增强）

**新增 4 个卡片**（按行为变量专属指标体系）：

| 卡片 | 内容 | 作用 |
|---|---|---|
| **衰减趋势** | 最近 12 周覆盖度折线图 + 衰减率数字 | 一眼看出趋势 |
| **稳定性监控** | 最近 12 周 PSI 折线图 + 当前 PSI 值 | 判断变量是否还能用 |
| **用户分群覆盖** | 按人群（白领/蓝领/学生）/ 地域 / 设备 三维分布饼图 | 评估样本偏差 |
| **隐私字段清单** | 字段名 + 隐私等级 + 用途说明 | 合规自检 |

**位置**：在现有"基础属性 / 技术属性 / 类型化属性" 之后，作为独立 Tab **"行为特征"**

## 5. 数据模型

### 5.1 行为变量扩展字段

在现有 `VariableAssetMock` 基础上，**新增**字段：

```ts
// 行为变量专属字段（仅 variableType ∈ {行为类, 交易类} 时有值）
behaviorMetrics?: {
  /** 数据来源系统（CDP / Tlog / 埋点 / 其他） */
  sourceSystem: 'CDP' | 'Tlog' | '埋点' | '其他'
  /** 行为事件类型 */
  eventType: '点击' | '交易' | '登录' | '浏览' | '其他'
  /** 活跃度（最近 7 天）0-1 */
  activityScore: number
  /** 衰减率（周环比）百分比 */
  decayRate: number
  /** PSI（稳定性） */
  psi: number
  /** 数据新鲜度（小时） */
  dataFreshnessHours: number
  /** 最近评估时间 */
  lastEvaluatedAt: string
  /** 衰减趋势（最近 12 周） */
  decayTrend: Array<{ week: string; coverage: number }>
  /** PSI 趋势（最近 12 周） */
  psiTrend: Array<{ week: string; psi: number }>
  /** 用户分群覆盖 */
  coverage: Array<{
    dimension: '人群' | '地域' | '设备'
    segments: Array<{ name: string; ratio: number }>
  }>
  /** 隐私字段清单 */
  privacyFields: Array<{
    field: string
    level: 'L0' | 'L1' | 'L2' | 'L3'
    purpose: string
  }>
}
```

### 5.2 现有字段复用

- `effectMetrics` —— 复用：评估区分度（IV/KS/AUC）
- `costMetrics` —— 复用：评估计算资源消耗（即将单价改为计算 CPU·秒）

## 8. 依赖与风险

### 8.1 依赖

| 依赖 | 说明 |
|---|---|
| **数据** | 行为变量的 `behaviorMetrics` 字段需要 mock 完整 |
| **指标** | 衰减率 / PSI / 活跃度 计算逻辑本期用 mock，生产环境接入 T+1 离线计算 |
| **图表组件** | 折线图 / 饼图 复用现有的 echarts 组件 |
| **现有页面** | 复用变量台账的列表 / 详情架构 |

### 8.2 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **行为变量数量少** | 演示效果不佳 | 至少补充 5 个 mock 行为变量 |
| **指标体系复杂** | 评审争议 | 第一阶段仅做核心 4 个指标（活跃 / 衰减 / PSI / 隐私） |
| **与其他专题冲突** | 后续外数 / 征信也可能需要专题 | 本期 PRD 显式约束仅行为变量，留扩展接口 |

### 8.3 不做（Out of Scope）

- ❌ 外数变量专题
- ❌ 征信变量专题
- ❌ 画像变量专题
- ❌ 行为变量自动评估 / 替换 / 下线流程
- ❌ 行为变量数据接入（依赖外部评估系统）
- ❌ 行为变量实时监控（本期仅 mock 静态数据）

|---|---|
| **行为变量** | 来源类型为"行为类"或"交易类"的变量，基于内部用户行为日志生成 |
| **活跃度** | 最近 7 天有数据的天数占比（0-1），反映变量的"生命力" |
| **衰减率** | 覆盖度周环比下降的百分比，反映变量的"衰退速度" |
| **PSI** | Population Stability Index，群体稳定性指标 |
| **隐私等级** | L0=无 / L1=行为 / L2=画像 / L3=身份，依据《个人信息保护法》分级 |
| **数据新鲜度** | 当前时间 - 最后一条数据时间，反映数据延迟 |

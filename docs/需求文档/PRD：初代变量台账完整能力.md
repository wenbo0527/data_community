## 1. 背景与目标

### 1.1 背景

变量台账 v1.1 已实现：
- 变量列表 / 详情 / 多视图（全部 / 效果 / 成本）
- 探索阶段 5 个新页面
- 变量中心状态同步机制（§6.5）

但**初代的"核心闭环"未补齐**：变量怎么进入台账、怎么走开发、怎么发布到生产、怎么和外部系统打通。

### 1.2 目标

补齐初代变量台账的 **4 大核心能力**：

1. **批量上传** —— Excel/CSV 一次性导入多个变量
2. **单个上传** —— 手动录入单个变量
3. **提交开发并发布** —— 变量注册后的全流程（开发 → 测试 → 发布到生产）
4. **系统打通** —— 与 OA（审批流）+ 变量中心（数据同步）的对接

### 1.3 业务闭环

```
[批量上传]  → 台账（草稿态）
                  ↓
[单个上传]  → 台账（草稿态） → 提交开发申请
                              ↓
                          [OA 审批]（合规 / 业务 / 技术）
                              ↓
                          [开发]（开发人员实施）
                              ↓
                          [测试]（QA 验证）
                              ↓
                          [发布到变量中心]（自动同步）
                              ↓
                          [生产上线]
```

## 2. 核心功能

### 2.1 批量上传

#### 入口
- 变量台账顶部工具栏："批量上传"按钮（在"新建变量"旁）

#### 流程

```
点击"批量上传"
    ↓
下载模板（Excel/CSV）
    ↓
填写变量信息 → 上传文件
    ↓
前端解析 → 数据预览（表格预览 + 字段映射）
    ↓
校验：必填字段 / 字段格式 / 重复检测
    ↓
校验通过 → 提交批量创建（一次创建 N 个变量）
    ↓
失败明细导出（哪些行失败 + 失败原因）
```

#### 模板字段（详见 §3.1）

- 提供 .xlsx 和 .csv 两种格式
- 模板带数据示例 + 字段说明 Sheet
- 支持 200 行 / 文件（可配置）

#### 交互细节
- **字段映射**：用户上传文件后，自动匹配中英文字段名（如"变量名称"/"name"/"variable_name" 都识别为同一字段）
- **重复检测**：上传前自动比对已有变量，标识"已存在"行
- **失败回滚**：任意一行校验失败，可选"全部失败回滚"或"跳过失败行"
- **进度反馈**：上传/解析/校验 三个阶段进度条

### 2.2 单个上传

#### 入口
- 变量台账顶部工具栏："新建变量"按钮

#### 流程

```
点击"新建变量"
    ↓
弹出表单 Drawer/Modal（多步骤表单）
    ├─ Step 1: 基础信息（名称、编码、类型、来源）
    ├─ Step 2: 技术信息（数据源、表/字段、计算逻辑）
    ├─ Step 3: 业务信息（业务标签、业务描述、责任部门）
    └─ Step 4: 确认提交
    ↓
校验（必填 / 格式 / 业务规则）
    ↓
提交 → 创建草稿变量
    ↓
跳转到详情页，可继续编辑或提交开发
```

#### 字段分组
- **基础信息**：变量名称、变量编码、变量类型、来源类型、数据源
- **技术信息**：源表/字段、计算逻辑、调度策略、SLA
- **业务信息**：业务标签、业务场景描述、责任部门、责任人
- **合规信息**：隐私字段清单、数据使用范围（详见 §3.1）

### 2.3 提交开发并发布

#### 流程

```
变量详情页（已审核通过的变量）
    ↓
点击"提交开发申请"按钮
    ↓
填写开发申请单（详见 §3.2）
    ↓
提交 → 触发 OA 审批流
    ↓
OA 审批通过 → 自动进入开发队列
    ↓
开发人员认领 → 完成开发（提交代码 + 自测报告）
    ↓
QA 测试 → 测试报告
    ↓
发布审批 → 自动推送到变量中心
    ↓
变量中心同步状态 → 已上线
    ↓
回写到台账：上线时间、版本号、监控指标
```

#### 状态流转

| 状态 | 触发 | 下一步 |
|---|---|---|
| 草稿 | 批量上传/单个上传 | 编辑 / 提交开发 |
| 待开发 | 提交开发申请 | OA 审批 |
| 开发中 | OA 审批通过 + 开发认领 | 开发完成 / 测试 |
| 测试中 | 开发完成 + QA 认领 | 测试通过 / 退回 |
| 待发布 | 测试通过 | 发布审批 |
| 已发布 | 推送到变量中心成功 | 运营监控 |
| 已下线 | 主动下线 / 失效 | 归档 |

### 2.4 系统打通

#### 2.4.1 与 OA 系统打通

**集成方式**：通过 OA 的 OpenAPI + Webhook

**对接内容**：

| 方向 | 内容 |
|---|---|
| **台账 → OA** | 提交开发申请 / 发布申请 / 下线申请 |
| **OA → 台账** | 审批结果回调（通过/驳回/转办） |

**字段映射**（详见 §3.4）：
- 台账字段 → OA 申请单字段（如台账的"开发需求描述" → OA 的"申请事由"）
- OA 审批结果 → 台账状态（"OA 审批通过" → 台账状态变为"待开发"）

#### 2.4.2 与变量中心系统打通

**集成方式**：通过变量中心的 REST API + 消息队列事件

**对接内容**：

| 方向 | 内容 | 机制 |
|---|---|---|
| **台账 → 变量中心** | 推送开发完成的变量 | REST API |
| **变量中心 → 台账** | 状态变更事件 | 消息队列订阅（§6.5 已有机制） |

**字段映射**（详见 §3.5）：
- 台账字段 → 变量中心字段（如台账的"计算逻辑" → 变量中心的"transform_logic"）
- 变量中心字段 → 台账字段（如"online_at" → 台账的"实际上线时间"）

#### 2.4.3 同步延迟容忍度

- **OA 审批回调**：5 秒内必须更新台账状态
- **变量中心状态变更**：1 分钟级（§6.5 已明确）
- **批量同步**：每日 T+1 全量对账一次

## 6. 依赖与风险

### 6.1 依赖

| 依赖 | 说明 |
|---|---|
| **OA 系统 OpenAPI** | 需 OA 团队提供审批流 OpenAPI 文档 |
| **变量中心 REST API** | 需变量中心团队提供推送 API 和事件订阅机制 |
| **文件解析库** | xlsx 解析用 SheetJS，CSV 解析用 papaparse |
| **状态机** | 状态流转需引入 XState 或自研 |

### 6.2 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **OA 接入复杂度** | 审批流配置复杂 | 第一阶段用固定模板，第二阶段支持自定义 |
| **字段映射不一致** | 数据丢失 | 字段映射文档化 + 单测覆盖 |
| **批量上传性能** | 200 行解析慢 | 流式解析 + Web Worker |
| **状态机复杂度** | 状态流转错误 | 状态机单测 + 集成测试 |

### 6.3 不做（Out of Scope）

- ❌ 自定义审批流配置（第一阶段用固定模板）
- ❌ 实时协同编辑（多人同时编辑一个变量）
- ❌ 变量版本管理（同一变量的多个版本）
- ❌ 字段级别的权限控制（本期仅变量级别）
- ❌ 自动发布（本期需要人工审批）

# 架构治理文档索引

本目录用于集中存放本轮新增的架构分析、治理规划与路线图文档，便于统一查阅和后续持续补充。

## 当前文档

### 1. 架构治理路线图

文件：`架构治理路线图.md`

用途：

- 汇总项目治理目标
- 说明治理主线和阶段计划
- 提供里程碑、验收标准与风险应对

### 2. 项目精简架构图

文件：`项目精简架构图.md`

用途：

- 快速理解仓库结构
- 理解主应用、子应用、共享层和 mock 数据关系
- 作为架构评审时的概览图

### 3. 分析与评估材料

目录：`分析/`

包含：

- `项目架构诊断报告.md`
- `子应用项目结构分析报告.md`
- `子应用成熟度评分表与治理清单.md`

### 4. 主应用退役与迁移方案

文件：`主应用退役与全子应用化迁移方案.md`

用途：

- 明确根 `src/` 作为历史过渡层的定位
- 给出迁移到 `apps/main-shell` 的分步路径与验收指标
- 作为“全子应用化”的落地参考

### 5. 变量中心技术设计

目录：`设计/`

包含：

- `2026-06-24-技术设计-变量全生命周期（变量中心）-v1.0.md`

## 建议用法

建议按下面顺序阅读：

1. 先看 `项目精简架构图.md`
2. 再看 `架构治理路线图.md`
3. 需要细节论据时，再阅读 `分析/` 中的报告

## 目录说明

- `docs/` 根目录：保留项目原有的业务说明文档与其他非治理类材料
- `docs/架构治理/`：集中存放本轮新增的架构分析、治理规划、路线图与评估材料
